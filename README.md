# クソゲー。GitHub Pages リニューアル版

今の `poran-no.github.io/kusoge-app-support/` を、このデザインに置き換えるためのフルコードです。

## 一番簡単な差し替え方

1. GitHubで `Poran-No/kusoge-app-support` を開く
2. いま置いてある古い `index.html` 等を削除
3. このZIPの中身を**フォルダごとではなく、中身をリポジトリ直下**へアップロード
4. Commit changes
5. 1〜3分ほど待って `https://poran-no.github.io/kusoge-app-support/` を再読み込み

GitHub Pagesがすでに公開できているので、Pages設定を作り直す必要は基本ありません。

## 入っているもの

- index.html
- style.css
- script.js
- assets/
- .nojekyll
